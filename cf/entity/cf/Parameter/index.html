Documentation

Definition
Named configuration input of a ProcessingStep that defines expected runtime bindings, defaults, allowed values, and value contracts.
Scope
Parameters document configurable inputs on the reusable step definition. Concrete values belong on ParameterBinding resources attached to PipelineNode instances, not on the step resource itself.
Example
Example: a FIFO buffering step can declare a windowSize parameter with an integer contract and a default of 10.
