Documentation

Definition
Column specification for table-shaped contracts, including name, element datatype, and nullability metadata.
Scope
TableColumnSpec describes one column inside a table-shaped contract, including name, datatype, and nullability. It belongs to schema metadata and should not be used as a row value instance.
Example
Example: a TableSchema can contain a TableColumnSpec for intensity values stored as nullable xsd:double.
